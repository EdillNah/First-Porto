## 📖 Tentang Proyek Ini

Website ini merupakan **portofolio web pertama** saya. 

Meskipun portofolio ini masih jauh dari kata sempurna dan terus berada dalam proses penyempurnaan, setiap elemen, struktur, dan baris kode di dalamnya benar-benar saya pelajari dan pahami secara mandiri. Mulai dari pemahaman semantik HTML, teknik styling modern dengan kombinasi CSS murni dan utility framework, manipulasi DOM dengan JavaScript dan jQuery, hingga optimasi animasi interaktif berbasis event dan Intersection Observer.

Bagi saya, proyek ini bukan sekadar halaman pajangan, melainkan tonggak awal (*first milestone*) dan bukti nyata dari proses belajar saya yang konsisten dan berkelanjutan di dunia pengembangan web.

---

## ✨ Fitur-Fitur Utama

- 🎨 **Modern Glassmorphism Navigation**: Navbar melayang (*sticky*) dengan efek *backdrop blur* dan desain minimalis elegan.
- 🌓 **Mode Gelap & Terang (Dark / Light Mode Toggle)**: Pengalihan tema secara instan yang menyesuaikan palet warna teks, latar belakang, dan wallpaper visual dinamis.
- ⌨️ **Efek Ketik Interaktif (Dynamic Typewriter Effect)**: Animasi teks ketik JavaScript murni yang berputar secara otomatis menampilkan peran (*Student*, *Developer*, *Designer*).
- 👁️ **Animasi Scroll Reveal (Intersection Observer API)**: Transisi halus elemen halaman yang otomatis muncul (`.muncul`) atau sembunyi (`.sembunyi`) secara performan ketika digulir ke dalam viewport.
- 🔤 **Tipografi Kustom Eksklusif**: Integrasi ragam font kustom (seperti *Danbury, Archivo Black, Bebas Neue, Space Mono, Excon, Will & Grace*) untuk memperkuat estetika dan identitas visual.
- 💼 **Showcase Proyek Terpilih**: Komponen grid kartu responsif untuk menampilkan proyek (misalnya aplikasi web edukasi genetika berbasis Hukum Mendel, *Genedu.id*).
- 📬 **Seksi Kontak Terintegrasi**: Bagian kontak informatif dengan tombol interaktif untuk terhubung langsung via Email, GitHub, dan LinkedIn.

## 🛠️ Teknologi yang Digunakan

| Komponen | Teknologi / Library | Keterangan |
| :--- | :--- | :--- |
| **Markup** | HTML5 | Struktur halaman semantik dan terorganisir |
| **Styling** | CSS3 & Tailwind CSS (CDN) | Layout fleksibel, animasi transisi, dan utilitas responsif |
| **Interaktivitas** | JavaScript (ES6+) & jQuery | Logika animasi ketik, manipulasi class, dan dark mode switcher |
| **Scroll Engine** | Intersection Observer API | Penanganan animasi scroll yang ringan dan efisien |
| **Aset Visual & Font** | Custom Typography & Graphic Assets | Koleksi font web kustom dan elemen ilustrasi grafis |

## 📁 Struktur Direktori

```text
├── assets/                  # Kumpulan gambar, foto profil, dan logo
│   ├── Font/                # Koleksi file font kustom (TTF, OTF)
│   └── Logo/                # Logo dan favicon situs
├── Font.css                 # Definisi @font-face untuk seluruh font kustom

├── script.js                # Skrip interaktivitas (typing effect & toggle)
├── style.css                # Styling utama, responsivitas, dan tema dark mode
└── README.md                # Dokumentasi proyek portofolio
```

## 🚀 Cara Menjalankan Proyek Secara Lokal

1. **Clone repositori ini:**
   ```bash
   git clone https://github.com/EdillNah/<nama-repo-kamu>.git
   ```
2. **Masuk ke direktori proyek:**
   ```bash
   cd <nama-repo-kamu>
   ```
3. **Buka halaman:**
   - Cukup buka file `index.html` langsung di browser favorit Anda, **atau**
   - Jalankan menggunakan extension seperti **Live Server** di VS Code untuk pengalaman pengembangan yang optimal.
